## 1. 任務目標

從第一性原理（First Principles）出發，建立太空級電磁閥（space-grade solenoid valve）的完整物理模型，目的：

1. 推導支配電磁閥行為的基礎物理方程式（不引用經驗公式，除非標明來源與適用範圍）
2. 識別各物理域的**硬性極限（physical limits）**：響應時間下限、功耗下限、洩漏率下限、小型化極限
3. 建立可執行的 Python 模型（電磁–機械–流體耦合），輸出參數掃描與權衡曲線
4. 產出設計參數速查表與響應特性圖

**應用場景**：衛星推進系統（冷氣推進、單基元 hydrazine、雙基元 MMH/NTO、綠色推進劑 ADN/HAN、電推進氙氣供給系統）之隔離閥與推力器閥（thruster valve / latch valve / isolation valve）。

## 2. 第一性原理分解（Physics Decomposition）

### 2.0 模型本體論（Ontology）——最簡物理項

所有後續模組必須能追溯至以下五個不可再分的原始項與三個儲能元件，不得引入無法對應的隱藏自由度：

**五個原始物理項：**
1. 載流線圈：安培定律，磁動勢 `NI`；自由度 = 匝數 N、線徑、繞線窗口
2. 可磁化鐵芯（磁軛＋銜鐵）：引導磁通、集中氣隙磁能；力的本質 `F = ½i²(dL/dx)`
3. 彈簧：胡克定律；唯一的關閉致動器（斷電關閉、抗振自保持）
4. 閥座＋poppet：可變節流面積 `A_eff(x)`，流體開關本體
5. 壓力差：`ΔP·A` 恆存在；直動式為阻力、先導式為助力

**三個儲能元件 + 一個耦合項（最小動力系統）：**
- `L(x)`：磁能（隨位置變化）、`m`：動能、`k`：位能
- 耦合項 `½i²(dL/dx)`：電磁域與機械域唯一的橋

所有 L1–L6 極限與第 5 節響應特性，最終都須表述為此最小系統的推論。

### 2.1 電磁域（Electromagnetics）

從 Maxwell 方程式出發，推導並驗證：

- **磁路歐姆定律**：`Φ = NI / Σℛ`，磁阻 `ℛ = l / (μA)`，重點在氣隙磁阻主導
- **Maxwell 吸力公式**：`F = B²·A_gap / (2μ₀)`（推導自 Maxwell stress tensor）
- **電感與氣隙關係**：`L(x) = N²/ℛ(x)`，電感隨銜鐵位置變化 → 電流特徵曲線的拐點
- **線圈電氣時間常數**：`τ_e = L/R`
- **磁飽和**：B_sat 對材料的限制（純鐵 ~2.15 T、Hiperco 50 ~2.4 T、430F 不鏽鋼 ~1.6 T）
- **渦流（eddy current）**：實心磁路的渦流延遲，趨膚深度 `δ = √(2ρ/(ωμ))`

### 2.2 機械動力域（Mechanical Dynamics）

銜鐵運動方程式（一維）：

```
m·ẍ = F_mag(x, i) − F_spring(x) − F_pressure − F_friction − F_flow(x, ṁ) − F_damping
```

- 彈簧預載 `F_preload = k·x₀`（決定關閉密封力與抗震能力）
- 壓力力 `F_p = ΔP·A_seat`（直動式）vs 先導式（pilot-operated）的力平衡差異
- 碰撞與反彈（seat bounce）→ 對響應時間與壽命的影響
- 振動環境下的自保持需求（launch vibration：隨機振動 ~20 g rms，衝擊 SRS）

### 2.3 流體域（Fluid Dynamics）

- **流量係數**：`Cv`/`Kv` 定義與從幾何推導等效流通面積 `A_eff`
- **氣體壅塞流（choked flow）**：`ṁ = C_d·A·P₀·√(γ/(R·T₀))·(2/(γ+1))^((γ+1)/(2(γ−1)))`
- 液體流：Bernoulli + 損失係數；**水錘效應（water hammer）**：`ΔP = ρ·c·Δv`（Joukowsky），對上游管路與閥座的衝擊
- 流體力對銜鐵的作用（flow force / Bernoulli force）

### 2.4 密封域（Sealing）

- 閥座接觸應力與洩漏率關係（金屬對金屬 vs 軟閥座 PTFE/PCTFE/Vespel）
- **氦氣洩漏率規格**：內漏典型 `≤ 1×10⁻⁴ ~ 1×10⁻⁶ scc/s GHe`，外漏 `≤ 1×10⁻⁶ scc/s`
- 洩漏物理下限：表面粗糙度、微觀通道的黏滯流/分子流（Knudsen number 判別）
- 顆粒污染敏感度 vs 密封力的權衡

### 2.5 熱域（Thermal）

- 線圈自熱：`P = I²R`，真空中**無對流**，僅傳導與輻射散熱
- 電阻溫度係數：`R(T) = R₀(1 + α·ΔT)`，銅 α ≈ 0.00393/°C → 熱態拉入電壓上升
- 磁性材料居里點與溫度退化
- 工作溫度範圍典型 −40°C ~ +70°C（推進劑閥另受 hydrazine 冰點 +1.4°C 限制 → 加熱器需求）

### 2.6 材料與環境域（Space Environment)

- 真空除氣（outgassing）：TML < 1%、CVCM < 0.1%（ASTM E595）
- 冷焊（cold welding）風險與 DLC/鍍層對策
- 輻射對聚合物密封件的劑量極限
- 推進劑相容性矩陣（hydrazine/MMH/NTO/H₂O₂/ADN 對 300 系不鏽鋼、Ti、PTFE、EPDM 等）

## 3. 物理極限分析（要求輸出）

針對以下每一項，推導極限來源、給出解析式或數值界限、並以 Python 參數掃描視覺化：

| # | 極限項目 | 支配物理 | 期望輸出 |
|---|---------|---------|---------|
| L1 | 響應時間下限 | τ_e = L/R + 機械行程時間 √(2mx/F) + 渦流延遲 | t_open 對線圈匝數/電壓/行程的掃描圖 |
| L2 | 功耗 vs 保持力 | F ∝ (NI)²，P ∝ I²R → F ∝ P·(N²/R) 受繞線窗口限制 | 功率–保持力 Pareto 前緣 |
| L3 | 小型化極限 | 繞線窗口面積、磁飽和、閥座直徑與 ΔP 力 | 質量 vs 口徑 vs 壓力等級曲面 |
| L4 | 洩漏率下限 | 表面形貌 + 分子流傳導 | 接觸應力 vs 洩漏率模型 |
| L5 | 壽命極限 | 閥座衝擊能量、疲勞、顆粒嵌入 | 撞擊速度 vs 循環壽命估計 |
| L6 | 電壓/溫度工作邊界 | 熱態拉入電壓 vs 母線電壓範圍（22–36 V typical） | 電壓–溫度工作包絡圖 |

**無量綱分析要求**：以 Buckingham π 定理整理支配無量綱群（例如磁力數、行程/氣隙比、電氣/機械時間常數比 τ_e/τ_m），說明尺度縮放律（scaling law）。

## 5. 響應特性分析（要求輸出）

1. **開啟瞬態**：電流曲線 i(t) 含拐點（銜鐵開始運動時 back-EMF 造成電流下陷）——此為無感測健康監測（current signature diagnostics）的基礎，須在模型中重現
2. **關閉瞬態**：斷電後 flyback 路徑（二極體 vs 稽納 vs RC）對關閉時間的影響，稽納鉗位可加速 3–5 倍
3. **Spike-and-hold 驅動**：高壓拉入 + PWM 降流保持，量化功耗節省與熱裕度改善
4. **溫度敏感度**：−40°C 與 +70°C 熱態下的 t_open、V_pull-in 漂移
5. **脈衝模式**：最小脈寬（minimum impulse bit 相關）、重複頻率極限（熱與機械）
